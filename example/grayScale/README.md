Gray Scale Example
==================

This example converts RGBA pixels with 8-bit channels to grayscale while retaining the alpha channel.
It is based on [Mattias Kretz's talk](https://github.com/CppCon/CppCon2023/blob/main/Presentations/stdsimd_how_to_express_inherent_parallelism_efficiently_via_data_parallel_types.pdf) about expressing parallelism with `std::simd`.
